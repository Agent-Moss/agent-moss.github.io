AARM 框架

三层防御架构

AgentMoss 是 AARM (Agent Armor Runtime Monitor) 框架的 TypeScript 独立版本，与 Python 版本和 Kernel 层检测系统共同构成完整的三层防御架构。

防御层组件检测粒度关键能力
L1 Hook AgentMoss (TypeScript) 命令行字符串 rm -rf / ✅、PDG 数据流 ✅、bash script.sh ❌
L2 Kernel secDetector (openEuler) syscall execve/unlink 穿透脚本 ✅、实时阻断 ✅、不理解意图
L2.5 语义 AgentSight (eBPF) TLS意图+syscall行为 因果关联 ✅、语义理解 ✅、不阻断
L3 关联 AARM 关联引擎 parentEventIds Hook+Kernel+语义 → 完整证据链
L1 Hook

AgentMoss (TypeScript)

AARM 框架 TypeScript 独立版本，本网站所介绍的组件。

概览

~6800 行 TypeScript 代码。Hook 监控方案，不依赖特定 Agent 框架。AgentArmor 论文方法已部分实现：PDG 图构建 + 安全标签格传播 + 16 条违规检测规则 + 属性注册表（61 个工具 + 10 个数据类型）。

  • 三层检测体系：L1 单点行为规则 → L2 长行为链规则（L2.1 基于PDG / L2.2 模型检测-已实现）→ L3 语义规则（待添加）
  • 29 个 Plugin Hook 覆盖点（8 个干预同步 + 12 个观察异步 + 9 个其他）
  • 130 条安全规则覆盖 12 个 ATLAS Tactic
  • 9 种 PDG 细粒度节点类型（SP/UP/LLM/TH/TN/TP/T/OBS/D）
  • SSE 实时推送 + Web Dashboard（6 个视图）
L1 Hook (Python)

AgentMoss (Python)

AARM 框架 JiuwenSwarm 旁路扩展版本。

概览

3520 行 Python 代码。仓库：https://gitcode.com/gcw_jnqaqu30/jiuwenswarm（分支 moss-demo-ui-1）。

  • 核心文件：extension.py (Hook注册)、monitor.py (核心引擎)、policy.py (253行策略规则)
  • 双模式接入：Extension Hook 回调 + DeepAgent Rail 旁路 patch
  • 配置：config.yaml（7类 block 开关、ask/block 阈值、sensitive_patterns）
  • 规则集：破坏性shell(12条)、网络外传(3+5条)、敏感路径(5条)、账号操作(6条)、持久化(6条)、混淆执行(2条)、Prompt注入(11条)、敏感信息(3+自定义)、行为链(2条)
  • web.py (SSE Dashboard, 2439行)
L2 Kernel

secDetector (openEuler)

openEuler 内构入侵检测系统，AARM 框架 Kernel 层的理想实现 (IDS+IPS)。

概览

仓库：https://gitee.com/yieux/secDetector。定位为 OS 内构入侵检测系统，基于 ATT&CK 模式库，提供实时阻断。

  • 架构：SDK + Service + Cases(8类探针) + Core(框架)
  • 工作流：hook → collect → analyze → response
  • 探针：进程(execve)、文件(unlink/rmdir)、行为(ptrace/pipe)、网络(connect)、内存(kmodule)、资源、账户、设备
  • 关键能力：内核级 syscall 监控，穿透脚本黑箱，检测 bash script.sh 内含 rm 等间接调用
  • SDK API：secSub(topic) / secUnsub / secReadFrom — AgentMoss 可订阅系统级事件
与 AgentMoss 的差异

secDetector 能阻断执行 (IPS)，但不理解 LLM 意图（纯行为检测）。AgentMoss 理解 LLM 意图（PDG 数据流），但不穿透脚本黑箱。

L2.5 语义

AgentSight (eBPF)

UC Santa Cruz eBPF 可观测性框架，弥合语义鸿沟。

概览

论文：arxiv 2508.02736 · 仓库：https://github.com/eunomia-bpf/agentsight · 6000行 Rust/C + 3000行 TypeScript 前端。

  • 定位：弥合语义鸿沟——理解 Agent 意图与行为间的因果关系，仅监控不阻断
  • 核心方法：边界追踪 (boundary tracing) — eBPF uprobes 拦截 TLS 明文 + tracepoints 捕获 syscall
  • 因果引擎：进程谱系 + 时间邻近性 + 参数匹配 → 辅助 LLM 语义分析
  • 性能：<3% CPU 开销
与 secDetector 的差异

AgentSight 理解意图（TLS拦截）但不阻断；secDetector 阻断但不理解意图。两者互补，AgentMoss 的 L3 关联引擎可整合两者证据链。
