使用指南

安装启动

三步部署 AgentMoss 监控服务，接入 OpenClaw Agent 运行时。

启动 AgentMoss 服务

# 克隆项目 git clone https://github.com/Agent-Moss/agentmoss.git cd agentmoss/agentmoss-demo # 安装依赖 pnpm install # 启动监控服务 pnpm dev # 服务启动在 http://127.0.0.1:19876 # 打开浏览器访问 http://127.0.0.1:19876 查看 Dashboard

运行测试

pnpm test # 运行所有测试 (26 个测试文件) pnpm typecheck # TypeScript 类型检查

环境变量

变量默认值说明
AGENTMOSS_HOST127.0.0.1监听地址
AGENTMOSS_PORT19876监听端口
配置

OpenClaw Plugin 配置

在 OpenClaw 运行时中配置 AgentMoss Plugin，连接到监控服务。

配置项默认值说明
enabledtrue启用监控
monitorUrlhttp://127.0.0.1:19876AgentMoss 服务地址
timeoutMs80干预检查超时（ms）
failClosedOnErrortrue故障时阻断（推荐开启）
observeHookstrue采集观察类事件
auditOnlyfalse仅审计模式（不阻断）
Fail-Closed 模式

当 failClosedOnError=true 时，如果 AgentMoss 服务不可用，所有干预类 Hook 将返回 block 决策，确保安全监控失效时不会静默放行危险操作。

API

API 接口

AgentMoss 监控服务提供 13 个 HTTP 接口，覆盖事件摄入、策略检查、行为图、安全 PDG 等。

方法路径说明
GET/主监控仪表盘
GET/api/health健康检查
POST/api/events事件摄入
GET/api/events事件列表（支持 runId 过滤）
GET/api/events/streamSSE 实时事件流
POST/api/tool-call/check工具调用策略检查
POST/api/hook/check干预 Hook 检查
GET/api/runs运行会话列表
GET/api/runs/:runId/graph行为图
GET/api/runs/:runId/security-pdg安全 PDG
GET/api/runs/:runId/evidence?eventId=证据链
GET/api/global/findings跨会话攻击链
GET/api/token-usageToken 消耗报告
